## AI engineering — two distinct capabilities

### 1. AI-augmented software development

- Uses AI as an engineering accelerator for requirements analysis, architecture
  alternatives, implementation, refactoring, test design, code review and
  technical documentation.
- Encodes coding standards, domain constraints and security checks into reusable
  prompts, commands and quality gates instead of relying on unrepeatable chat
  sessions.
- Keeps human review and deterministic CI checks in the decision loop; generated
  code is treated as untrusted until compiled, tested, scanned and reviewed.
- Applies repository context, bounded task decomposition and model routing to
  improve output quality while controlling token cost and latency.
- Uses AI-assisted incident analysis to correlate telemetry and propose ranked
  hypotheses; operational decisions remain traceable and owned by engineers.

### 2. AI systems for production and client use cases

- Designs RAG and semantic-search systems with explicit retrieval evaluation,
  source attribution and protections against prompt injection and data leakage.
- Builds structured LLM workflows with runtime validation, retries, timeouts,
  fallback behaviour and human approval for high-impact actions.
- Designs document-intelligence pipelines for OCR, extraction, confidence
  scoring and exception handling.
- Exposes predictive and generative capabilities through versioned APIs that can
  be observed, tested and integrated into existing products.
- Defines golden datasets, quality thresholds, model/cost routing, token usage
  tracking and production telemetry before scaling an AI use case.
