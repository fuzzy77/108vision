## Team leadership — mobile + AI delivery

### 1. Lead mobile delivery as a hands-on contributor

- Makes the right mobile stack choice for the context: Blazor Hybrid / MAUI when the
  team is .NET-first and can share domain logic directly (internal tools, B2B, existing
  .NET shop); React Native / Expo when cross-platform TypeScript ROI is clear. PWA when
  neither is justified. Explicit trade-off, documented decision.
- Reviews React Native / Expo code (TypeScript) with strict typing, Zod validation,
  offline state management, secure credential storage and no auth reimplementation on
  the mobile layer.
- Reviews Blazor Hybrid / MAUI code (C#, Razor, MVVM) with the same standards applied
  to backend .NET services: DI, Result pattern, Polly resilience, structured logging,
  JWT validation.
- Establishes EAS Build and MAUI CI/CD pipelines; coaches the team on mobile-specific
  testing — component tests, device targets, network failure handling, offline scenarios.
- Uses Python for team tooling: automation scripts, data pipelines, AI prompt
  orchestration, operational utilities — shared and maintained, not throwaway code.

### 2. Make AI a controlled development tool

- Defines team conventions for allowed tools, context boundaries, sensitive data and
  human review.
- Teaches developers to decompose work, provide bounded context and verify generated
  code instead of accepting plausible output.
- Converts recurring domain and coding rules into reusable prompts, commands,
  checklists and CI feedback.

### 3. Help the team build product AI safely

- Splits AI features into testable parts: retrieval, orchestration, validation,
  business rules, provider adapters and user experience.
- Introduces evaluation scenarios and acceptance criteria before scaling.
- Makes latency, cost and quality signals visible to the team.
