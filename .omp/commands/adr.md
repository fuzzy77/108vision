Create an Architecture Decision Record (ADR) for the decision I describe.

Format:

```markdown
# ADR-NNN: <Title>

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Superseded
**Decider:** Elios Scoglio

## Context

What situation or problem forces this decision?
What constraints exist (technical, business, operational)?

## Decision

What have we decided?

## Alternatives Considered

| Option | Pros | Cons |
|---|---|---|
| Option A (chosen) | ... | ... |
| Option B | ... | ... |

## Consequences

**Positive:**
- ...

**Negative / Trade-offs:**
- ...

**Risks:**
- ...

## Rollback Plan

How to reverse this decision if it proves wrong?
```

Save the ADR in `aia-platform/docs/adr/ADR-NNN-title.md`.
